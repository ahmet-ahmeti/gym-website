# Iron Forge - Gym Website

A multi-page gym website built as a university project.

## Pages
- **Home** — hero section, training programs, subscription plans
- **BMI Calculator** — calculates BMI with a visual result bar
- **Schedule** — recommended weekly training schedule
- **Contact** — contact form with Google Maps integration
- **Shop** — supplement shop with a working cart

## Tech
HTML, CSS, JavaScript

## How to Run
Open `index.html` in a browser - no setup needed.
